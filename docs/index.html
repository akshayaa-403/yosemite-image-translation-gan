Your photo still loads and displays above, but there is no model to run it through: this page reads ONNX files from docs/models/ and that folder is empty. The fastest way to fill it is the Colab notebook in the repo (notebooks/train_and_export.ipynb) — it downloads the dataset, trains, exports both directions, and hands you the two files to commit. 

python scripts/prepare_data.py --source kaggle
python scripts/train.py --config configs/yosemite_128.yaml
python scripts/export_onnx.py --checkpoint runs/yosemite_128/checkpoints/latest.pt --quantize

Two generators are trained on unpaired photographs — a pile of summer shots and a separate pile of winter ones, with no correspondence between them. The cycle constraint (summer → winter → summer must return your image) is what ties the output to your photo rather than to some plausible unrelated winter scene. Architecture, training recipe and metrics are in the README; execution is ONNX Runtime Web on WebGPU where available, WebAssembly otherwise.
